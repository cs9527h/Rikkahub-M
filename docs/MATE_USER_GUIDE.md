# Mate 使用说明 / User guide

> **当前状态：源码集成预览，尚未提供经过编译和真机测试的 Mate 安装包。**
>
> 本指南只描述当前实际提供的入口以及尚待完成的功能。不要将服务器配对与已实现聊天／记忆同步混淆。

## 产品定位

Mate 是面向 Android 的个人 AI 聊天客户端，基于 RikkaHub 的开源 Kotlin、Jetpack Compose 和 Material 3 Expressive 架构。使用者可以独立配置 AI 提供商，也可以通过 Mate 专属的协议 3 网关连接现有 AstrBot／李鱼服务端（目前开发中）。

本项目是非官方 RikkaHub Fork，不代表 RikkaHub 官方立场。保留原作者版权与 AGPL-3.0 许可。

## 1. 独立 API 模式（继承 RikkaHub）

1. 在「快速开始 → 独立 API」或「设置 → 提供商」增加自己的 API 服务商。
2. 填写服务商提供的密钥，添加具体模型，并设置默认聊天模型。
3. 在聊天界面开始对话。聊天列表、模型、Markdown 等由上游原生架构提供。

Mate 不提供模型额度，也不会替使用者生成或付费购买 API 密钥。

## 2. 李鱼／AstrBot 设备连接（目前仅配对与验证）

1. 在「快速开始 → 李鱼 · Mate」或「设置 → 连接李鱼服务器」打开页面。
2. 填写 HTTPS 网关基础地址（不能带账号、路径、查询参数）。
3. 在已授权的服务端或另一台已授权设备生成一次性配对码，填写配对码和设备名称。
4. 点击「配对并连接」。客户端尝试兑换凭据并验证网关协议 3 与服务器实例 ID。
5. 已保存的设备凭据使用 Android Keystore 加密。本机可检测连接或移除本机授权；移除本机授权不会撤销服务器上的设备。

**重要限制：** 当前 Mate 专属功能分支没有把协议 3 网关接进 RikkaHub 的 ChatService，因此配对成功不代表可以直接和李鱼聊天。还没有可视化服务端管理页面、二维码扫描或首台设备配对码生成器。

## 3. 记忆、历史与数据安全

- RikkaHub 本地记忆与 AstrBot 服务器端李鱼记忆彼此独立。
- 目前尚未实现 Mate 的远端记忆读取／增删改、李鱼自主成长、聊天历史和跨设备同步。
- 旧 Mate 与 RikkaHub 的数据库结构不同，未验证前不要卸载旧 Mate、清除旧数据或尝试以新 APK 覆盖。
- 所有者验证和记忆管理的服务器权限必须由服务端执行，不可凭昵称或客户端输入推断授权。
- 本仓库是公开的，禁止提交用户聊天、Token、设备凭据、服务器私钥和生产配置。
