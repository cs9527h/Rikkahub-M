## 产品定位

Rikkahub-M 是基于 [RikkaHub](https://github.com/rikkahub/rikkahub) 的非官方 Android AI 客户端。它以模型 API 直连、本地助手、自定义提示词、本地聊天与备份为开发方向，不再使用原 Mate/AstrBot 专用网关配对进行聊天。旧文档中的「Mate 服务器」「配对码」「服务器长期记忆」等操作**已不适用于当前架构**。

## 使用方式（在安全验收后的可用版本中）

1. 打开 App 的模型供应商设置，添加自己拥有的模型 API 地址与密钥。
2. 配置要使用的模型，将它选为聊天模型。
3. 创建或编辑本地助手，按需配置提示词或导入 Markdown/TXT/JSON 规则。
4. 使用聊天界面开始对话，并按实际版本配置历史记录和本地记忆。
5. 使用 WebDAV/S3 备份功能前，先确认当前版本的加密和恢复流程已完成验收。

Rikkahub-M 不赠送模型额度，也不会代替用户购买 API 密钥。具体设置入口与功能可用性以实际安装版本为准。

## 隐私及备份注意事项

- HTTPS 传输加密不等于备份文件端到端加密。
- 未经端到端验证的普通 ZIP 备份不可安全地视为加密归档。
- 不要向不可信存储上传包含聊天正文、人格或 API 密钥的文件。
- 更新之前保留原应用与独立备份，确认发布说明未列出数据损坏或迁移风险。

### 从导入的聊天提取长期记忆

在**助手 → 记忆 → 历史提取**选择会话和保存位置。确认模型服务、发送范围和费用估算后开始。提取完成后，在候选里检查原话，编辑并保存需要的记忆。之后可以在**使用记录**查看新聊天发送给模型的记忆片段。详见[历史提取与长期记忆](HISTORY_MEMORY.md)。
