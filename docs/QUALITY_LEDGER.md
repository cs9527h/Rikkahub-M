# 质量与需求台账

每个版本更新本文件；未完成项自动延续到下一版，不得因为发了新版就关闭。

## 长期铁则

1. 流畅度不得倒退：每次发布对比上一稳定版性能基线，回退超 10% 先修再发。
2. UI 保持简洁：删无用文案、无意义设置和重复入口。
3. 功能真实可用：不做假开关、静态展示、占位接口。
4. 保护数据：不删记忆、聊天、配置、头像、连接信息。
5. 架构统一：RikkaHub 前端 + Mate 网关，只有一套聊天系统。
6. 持续清旧账：每版先看本台账。
7. 性能门禁永久保留，`docs/perf/README.md` 与 `scripts/perf_compare.py` 不得移除。

### P1 / P2 延续

- 附件：8MB / 4 个的真实端到端未在真机验收。
- 备份：导出会剥离所有 `apiKey` 与密码，恢复后需重新授权，UI 提示需真机确认。
- 通知：真机需复验标题、头像、点击进入会话、锁屏行为。
- 文案：设置页仍有长句，后续按"能一两个词说清就不用整句"继续收。
- 人格：李鱼自然化与渐进成长沿用现有配置，未做提示词叠加。

- 客户端：编译 + 单元测试 + 预览构建。
