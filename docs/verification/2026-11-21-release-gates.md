## 稳定版放行条件（全部满足才可发布）

- 同一提交上：Android 编译 + 全部 JVM 单测 + 全部仪器测试全绿。
- 真机：安装、升级覆盖（旧 code → 新 code）、启动、聊天、备份/恢复、无数据丢失。
- 性能：与基线同一设备/条件对比不劣于门槛，记录原始数据。
- 签名：证书指纹一致、code>15、单一 universal APK、校验和与发布说明。
- 服务器：仅备份存储；不引入网关/配对/人格注入。
- 若不满足：保留草稿 PR 与明确的测试预览版，不发布稳定版。
