# 0.4.1 覆盖升级与恢复验收清单（待执行）

前置：一台已安装 **code 15（0.4.0 测试预览）** 的 Android 设备，保留原数据；准备同一签名的 code 16 APK 与 SHA-256。

## 安装与签名

- [ ] `apksigner verify --print-certs` 显示证书 SHA-256 = `e4b90a5f274074e2d8dbfa4d68226c0941635b6792716b89fd805a2318f2c94a`。
- [ ] `aapt dump badging` 显示 `versionCode='16'`、`versionName='0.4.1'`、包名 `com.rikkahub.mate`。
- [ ] 直接覆盖安装（不卸载、不清数据）成功；原有聊天、助手、设置仍在。
- [ ] 旧 Mate 聊天库/旧备份目录在升级后仍存在（未要求恢复为当前数据源，但不得被删除）。

## 启动与聊天

- [ ] 冷启动无崩溃；首次进入不出现强制迁移/清空。
- [ ] 新建会话、流式输出、停止生成、错误提示正常。
- [ ] 前台生成通知显示当前会话的助手；缺失身份时显示应用名，不显示其他助手。

## 备份与恢复（设置类）

- [ ] 设置页保存自动备份口令后，手动触发自动备份；远端出现 `backup_settings_*.rkmbak`。
- [ ] 修改设置/人格/记忆后再次触发；只有内容变化才产生新归档；仅改变启动次数或上次备份时间不产生新归档。
- [ ] 更换恢复口令后触发；即使内容未变也重新上传，新归档可用新口令解密。
- [ ] 恢复设置归档：重启后设置、人格、记忆回到归档内容；归档生成后新增的对话仍保留。
- [ ] 恢复后“最近删除”中的记忆仍处于回收站，不自动复活。

## 备份与恢复（聊天类）

- [ ] 远端出现 `backup_chats_*.rkmbak`；不含 `settings.json` 与附件。
- [ ] 恢复聊天归档时未勾选“聊天记录”会给出明确错误而不是静默成功。
- [ ] 勾选后恢复：会话恢复为归档时点；恢复前刚写入的最新本地记忆仍保留。

## 失败与取消

- [ ] 错误口令恢复失败，原数据不变，暂存区被清理。
- [ ] 飞行模式触发自动备份：记录脱敏失败原因，重试有上限，不产生明文上传。
- [ ] 清除本机自动备份口令后自动任务被取消，重新保存新口令后状态清空并强制上传。

## 性能

- [ ] 与基线同设备、同条件对比冷启动；记录原始多次测量与中位数。
- [ ] 对比结果不劣于验收门槛才可发布；不得修改阈值或删除测量。

## 记录

把设备型号、系统版本、APK SHA-256、签名指纹、每项结果与原始日志追加到本文件后再决定是否发布稳定版。
