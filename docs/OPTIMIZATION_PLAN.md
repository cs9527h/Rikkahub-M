# Rikkahub-M 全面优化计划

用户确认范围：85 项，8 个领域。基线：v1.1.6（versionCode 63）。所有任务初始为待源码核对，未声称已实现或已验收。

## 永久原则

保护聊天、记忆、助手、头像、附件、凭据和配置；复用现有架构；保留独立包名、签名、更新渠道、Android 8.0、双 ABI、无广告及 AGPL-3.0 署名。不擅自恢复强制备份加密或旧网关。不关闭检查或删除功能来伪造优化。远程记忆检索与跨供应商传输须明确授权。

## 任务与验收清单

### 性能与流畅度（10项）

- [ ] RM-001 **冷启动** — 延迟非必要初始化；同机 P50 目标降低15%。
- [ ] RM-002 **长对话** — 分页及稳定 Key；万条消息无崩溃。
- [ ] RM-003 **流式输出与 Markdown** — 增量解析；文本完整、掉帧减少。
- [ ] RM-004 **键盘动画** — 统一 IME Insets；无跳动遮挡。
- [ ] RM-005 **图片加载与缓存** — 按尺寸解码；重复加载无异常内存增长。
- [ ] RM-006 **内存占用** — 排查泄漏；压力测试无持续增长。
- [ ] RM-007 **后台耗电** — 减少轮询唤醒；同场景耗电下降。
- [ ] RM-008 **动态背景** — 不可见暂停；保持视觉效果。
- [ ] RM-009 **文件扫描与搜索** — 异步增量索引；不卡主线程。
- [ ] RM-010 **真机基准** — Macrobenchmark/Perfetto；记录设备、P50/P95、掉帧、内存、耗电。

## 执行顺序

1. 全量审计、基线、工程治理与社区建设。
2. 数据安全、备份与迁移。
3. 性能与流畅度。
4. UI 与交互。
5. 模型与 API。
6. 长期记忆。
7. 上游同步复核与综合验收。紧急修复贯穿各阶段。

## 验收与发布门禁

每项记录源码路径、SHA、当前状态、风险、实施方案、测试结果、提交及遗留事项。先核对已有功能，不重复开发。保留现有性能门禁，关键指标回退超过10%暂停发布；量化目标须经基线确认。单测、仪器测试、Web测试、Lint、迁移、恢复回滚、签名及APK校验通过；无真机或凭据时标记待验收，不虚报。未完成项延续到后续版本，不为版本号发布。
