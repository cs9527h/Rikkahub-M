## 交付门槛
1. 每项功能形成「实际代码 → 可重复单元/契约测试 → CI → 真机或生产合成数据验收」证据链。
2. 服务器和客户端不可相互宣称对方已完成；真实用户人格/记忆禁止用于测试或批量重写。
3. 包名与签名保持兼容，仅生成 universal APK；不能验收时保留 preview，不抢发稳定 0.4.0。
4. 用户只需安卓手机，打包由 GitHub Actions 完成。
5. 配套服务器计划：cs9527h/dafayu-android#34。
