# 1.1.5 技术说明

## 版本与范围

- 上一正式版：`v1.1.4`；开发基线：`fe1ae9594762fe12e756271fa81a508f616264b9`。
- 版本：`1.1.5 / versionCode 62`。
- 包名：`com.rikkahub.mate`；沿用既有签名和arm64-v8a+x86_64通用APK策略。
- 数据库schema与备份格式不变，不新增数据库迁移。

## 改动

1. 文件管理增加原生预览、单文件导出、类型/助手归属筛选、搜索、排序与限定筛选范围的清理。
2. 图片可缩放；PDF逐页渲染；文本/代码/Markdown有界预览；DOCX/PPTX/EPUB提取文字，其他格式通过临时只读FileProvider授权交给系统应用。
3. 真实附件归属覆盖所有分支与嵌套工具输出，分页扫描并用路径哈希索引归类；损坏或超限历史不冒充未关联文件。共享附件和清理范围显式确认，磁盘删除失败保留索引。
4. 记忆页增加独立助手选择，不更改当前聊天助手；只合并所改记忆/提醒字段，保留并发更新；失效的显式助手不回退写入其他助手。
5. 设置Web服务器品牌改为Rikkahub-M，移除快速入门多余导入标题但保留ZIP导入功能；补齐文件管理8套语言资源。

详细行为见[文件管理说明](<../features/storage-file-manager.md>)和[记忆助手选择说明](<../features/memory-assistant-selection.md>)。
