# Rikkahub-M 0.9.3 技术说明

发布日期：2026-11-24 ｜ versionCode 39 ｜ 上一版 0.9.2

本版是**纯视觉回退**：把聊天页的外观恢复到上游 RikkaHub，撤掉 0.8.8 / 0.8.9 / 0.9.0 / 0.9.1 四版里我按截图数据调的
间距、排版与背景。用户反馈「看着有点不对劲」，以上游为基准重新对齐，不再叠加自定义观感。

## 一、回退了什么（逐文件）

## 二、没有跟着回退的部分

这些是功能差异，不是视觉差异，保留：

- 记忆中心入口、工具调用卡片、附件/媒体创作、语音与翻译、消息操作菜单（复制/重生成/分叉/收藏/删除确认）
- 0.9.2 的全部安全与启动改动
- `Assistant.useGradientBackground` 默认仍是 `false`（与上游一致）

## 三、副作用（需要下一版复核）

1. **动态渐变背景耗电**：上游实现是无限动画（无节流），0.8.8 的 22fps 节流版被撤掉。若真机耗电明显，需要在不改变观感的前提下重新加节流。
2. **浅色空态回到 `surface`**：没有壁纸也没有开动态渐变时，聊天页就是 `colorScheme.surface`（0.9.0 曾判定为「死白」）。这是上游的既有行为，本版按用户要求接受。
3. **正文略大、消息间距略宽**：恢复 16sp/24sp 与 12dp 间距，行宽比 0.9.2 松一档。
