# Rikkahub-M 0.9.8 技术说明

发布日期：2026-11-24 ｜ versionCode 44 ｜ 上一版 0.9.7

两处调整，都在备份口令这一条线上。

## 一、自动备份也支持口令

之前自动备份固定用本机 Keystore 里的随机密钥（`EncryptedBackupSession.run(passphraseStore::readOrCreate)`），
换机只能靠「恢复密钥文件」。

现在「高级设置 → 自动备份」新增：

| 项 | 行为 |
| --- | --- |
| 自动备份口令（设置） | `BackupVM.setBackupPassphrase()` → `BackupPassphraseStore.save()`（AES-GCM + Keystore 包裹落盘，最少 6 位）。自动备份与「立即备份」都会读到这把口令 |
| 重置为本机随机密钥 | `setBackupPassphrase` 的反向操作：清空后 `readOrCreate()` 重新生成 32 字节随机密钥 |

要点：

- 口令只影响**新建**的备份；已上传的旧备份仍用它们各自的口令解密，不会失效；
- 恢复密钥文件导出的就是当前生效的口令/密钥，两者保持一致；
- 设置口令后，另一台设备**只输口令**即可恢复，不需要导入密钥文件；
- 忘记自定义口令后，用该口令生成的备份无法恢复（AES-256-GCM，无后门），UI 里已用红字提示。

## 二、恢复口令不限次数

`BackupPage` 的两条恢复路径（本机文件 / WebDAV / S3）里，口令错误的重试上限（原 3 次）已移除：

- 输错 → 弹框继续输入，直到用户点「取消」；
- 关闭弹框 = 放弃，恢复终止，不留半成品（暂存目录由 `PendingRestore` 在下次启动清理）。

## 三、验证

```bash
./gradlew -Pandroid.aapt2FromMavenOverride=$AAPT2 :app:compileGithubDebugKotlin
./gradlew -Pandroid.aapt2FromMavenOverride=$AAPT2 :app:testGithubDebugUnitTest
./gradlew -Pandroid.aapt2FromMavenOverride=$AAPT2 spotlessApply
python3 -m unittest discover -s scripts -p "test_*.py"
```

本机：编译通过、单元测试通过、脚本契约测试 69 例通过。真机端到端（设口令 → 另一台设同口令 → 导出 → 恢复）仍需设备。

## 四、兼容性

- 无数据库迁移；versionCode 44，可覆盖升级 0.9.7；
- 旧备份（8 位口令或本机密钥）继续可恢复，口令长度下限只作用于新设置。
