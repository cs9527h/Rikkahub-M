# Rikkahub-M 0.9.11 技术说明

发布日期：2026-11-25 ｜ versionCode 47 ｜ 上一版 0.9.10

0.9.10 把备份加密整层去掉后，留下了一批「只为加密服务」的死代码。这一版清掉它们，并跑一轮回归。

## 清理清单（全部 grep 证明零引用）

| 删除 | 证据 |
| --- | --- |
| `EncryptedBackupSession.kt` + `EncryptedBackupSessionTest.kt` | 自动备份改为明文后，生产代码零引用，只剩它自己的测试 |
| `BackupArchiveFormat.exportPassphrase()` + 5 个对应用例 | 导出不再接受口令，测试是唯一调用方 |
| `BackupVM.automaticPassphraseConfigured` | 设置页的口令入口已移除，没有任何 UI 读取 |
| `BackupVM.forgetAutomaticBackupPassphrase()` | 零调用 |

保留：`MissingBackupPassphraseException`（抽成独立文件）——只有恢复 0.9.9 之前的加密备份时还会用到，
界面据此弹一次口令框；`BackupPassphraseStore` 也只服务这条旧路径与「导入恢复密钥文件」。

## 顺带修掉的告警

- `UpdateNotes`：两处 `!!` 改为 `?:` 安全写法；
- `NotificationAvatar`：`when` 已穷尽，删掉多余的 `else`。

## 验证

```bash
./gradlew -Pandroid.aapt2FromMavenOverride=$AAPT2 :app:compileGithubDebugKotlin
./gradlew -Pandroid.aapt2FromMavenOverride=$AAPT2 :app:testGithubDebugUnitTest
python3 -m unittest discover -s scripts -p "test_*.py"
```

本机：编译通过、单元测试通过（含 `UpstreamBackupCompatTest` 3 例）、脚本契约 69 例通过。

## 仍未覆盖（诚实列出）

- 真机/模拟器端到端：100MB+ 备份的导出与恢复耗时、进度条观感、原版备份实际导入；
- i18n（界面可见的少量中文字面量）、无障碍 `contentDescription`；
- ABI 瘦身（只发 arm64）需要产品决定；
- 宽屏/大字号截图回归仍依赖 CI `ui-screenshots`。
