# Rikkahub-M 0.4.2

## 备份与恢复
- 日常备份/恢复不再要求输入口令：恢复口令只需在开启加密时设置一次，之后手动与自动备份静默复用；界面只显示“已开启/已关闭”。
- 保留“更换口令 / 关闭加密”，关闭时停止自动备份并清除本机口令，绝不静默降级为明文。
- 旧加密归档（PBKDF2+AES-GCM，`.rkmbak`）保持可恢复；跨设备恢复只需在新设备上输入一次原口令。
- 自动备份仍按“设置/聊天”两类分别检查、失败重试、保留最近 N 份，聊天附件不进入自动备份。

## 更新系统
- 修复更新日志闪退：`Screen.MateChangelog` 已在导航中注册。
- 更新日志改为读取本仓库 GitHub Releases，和“检查更新”共用同一份数据，不再内置会过期的版本列表。
- 关于页点击版本号立即检查更新：检查中 / 已是最新 / 发现新版本（可直接打开下载页）/ 失败可重试。
- 启动后异步自动检查（默认开启，12 小时间隔），只认本仓库正式 Release，不把上游或预览版当更新。

## 界面与文案
- 删除 Mate 网关遗留文案与“测试构建”记录，统一使用 Rikkahub-M 名称与真实版本号。
- 备份安全说明合并为一处，不再重复解释技术细节。

## 未完成

- 自动备份保留清理的网络删除路径未在真实存储验证。
