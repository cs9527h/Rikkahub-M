# Rikkahub-M 0.8.3

发布策略：0.8.3 是记忆页入口位置的可用性修复。只调整 UI 结构与版本号，不改数据库、不改记忆内容、不改人格与聊天。

## 变更

- 记忆首页顶栏新增「⋮」菜单：记忆使用记录、高级设置直接进入，不再需要滚到列表最底部。
- 删除页面底部重复的「使用记录 / 高级设置」卡片，记忆列表更短。
- 二级页返回逻辑不变；`BackHandler` 与返回按钮仍回到记忆首页。

## 兼容

- 无 Room 迁移，数据库版本仍为 39。
- 包名、签名、记忆库、候选与人格配置不变。

## 验证

- PR CI：Kotlin 编译、JVM 单元测试、发布门禁脚本。
- 正式发布流水线：模拟器 instrumented、Android Lint、签名通用 APK、升级校验。
