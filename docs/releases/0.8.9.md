# Rikkahub-M 0.8.9

发布策略：0.8.8 的视觉改动方向对（删掉顶栏遮罩、收消息栏），但执行过头——标题被包进大白色胶囊、背景整屏偏蓝。0.8.9 做的是「纠偏」而不是再加大改动量：把顶栏和背景拉回中性，同时把消息区与输入框真正收紧。无数据库迁移，不动包名与签名。

## 一、顶栏：从「白胶囊 + 白带」到「向下淡出」

0.8.8 的做法是让标题套一个 `ChatTopBarCapsule`——滚动后标题变成一个独立白胶囊，与左右两个按钮胶囊并排，顶部被割成三个白色区域，这是用户反馈的「突兀」。

0.8.9：
- 标题恢复为简洁的两行文字（会话名 + 助手名），不再有独立胶囊背景；
- 左右两个按钮保留原有圆角胶囊（这是原版 Rikkaub 的识别度，不撤销）；
- 滚动后的可读性由**顶栏自己的一层向下渐变**提供：`surface` 在顶部 0.58、中部 0.28、到顶栏底部完全透明，随 `listScrolledUnderTopBar` 用 `animateFloatAsState` 淡入。没有硬边、没有整栏白块，与聊天背景连续衔接。

## 二、背景：在三版之间找中间档

三代取值的对照：

| 版本 | 浅色底渐变 | 问题 |
| --- | --- | --- |
| 原版（180c2b57） | `#AFD0F2 → #CBE0F6 → #F1F7FD → #FFFFFF → #FFFFFF` | 下半屏纯白，刺眼 |
| 0.8.8 | `#BCD8F0 → #CBDEF1 → #D5E4F1 → #DCE8F3 → #E1EBF5` | 整屏泛蓝，缺层次 |
| 0.8.9 | `#D7E7F7 → #E4EEF8 → #ECF2F9 → #F0F4FA → #F3F6FA` | 顶部只略蓝、底部比纯白暗一档（243/246/250） |

光斑浓度同样取中间：PR #38 降到 0.25/0.18/0.20/0.13 几乎看不见（丢层次），0.8.8 是 0.44/0.30/0.36/0.20（偏重），0.8.9 用 0.34/0.24/0.26/0.16。暗色配色未改（0.8.8 的 `#18243C → #070A12` 已被确认不发灰）。

## 三、消息区：48dp 底部留白是加倍出来的

原来写的是：

```kotlin
contentPadding = PaddingValues(16.dp) + PaddingValues(
    top = innerPadding.calculateTopPadding(),
    bottom = 32.dp + innerPadding.calculateBottomPadding(),
)
```

`PaddingValues.plus` 是**相加**，所以真实底部是 16 + 32 = 48dp，不是注释以为的 32dp——最后一条消息离输入框有两指高，这是「消息区松散」的主因。

改为 `start/end = 12dp`、`top = innerPadding.top + 12dp`、`bottom = innerPadding.bottom + 20dp`：底部 -28dp，窄屏正文多 8dp 宽。列表间距 `12dp → 8dp`（消息内部本来就有 4dp + 32dp 操作栏 + 28dp 头像行，叠加后仍有充分间隔）。

## 四、正文穿透标题

`topFadingEdge` 旧曲线是 `0f 透明 → 0.6f alpha 0.15 → 1f 黑`，在标题带里还留着 15% 可见度，长段落滚过去会和标题文字叠。改为：标题带内 alpha 恒 0（两个同色 stop），出栏后再用 24dp 线性淡入——没有硬边，也不需要再加任何背景遮罩。`ChatListPreview` 的调用点签名兼容，未改。

## 五、输入框

- `TextField` 的 `contentPadding` 从默认 16dp 收到 `start/end 12dp、top/bottom 6dp`：聚焦态高度 **80dp → 60dp**，空态仍受 M3 `TextFieldDefaults.MinHeight = 56dp` 约束 → 空态与打字态的跳变从 24dp 收到 4dp。`lineLimits = MultiLine(maxHeightInLines = 5)` 保持，多行扩展不受影响。
- 底部渐变遮罩：颜色从 `colorScheme.background`（浅色下是偏白 surface，会在淡蓝灰背景上糊出一块更白的区域）换成输入框自己的 `containerColor`（`surfaceContainerLow`），alpha 上限 0.82 → 0.6。`startY/endY` 与 `imeInsets` 逻辑未动。
- 键盘避让沿用 0.8.8 的 `ime.union(navigationBars)`，不再叠加 padding。

## 保留（明确不做回滚）

- 消息默认操作只留复制 / 重新生成 / 更多；朗读与停止朗读、翻译（含语言选择）、选择复制、网页预览、编辑、分享、分叉、收藏、删除在「更多」菜单里；删除有二次确认（0.8.8 修的回归不撤销）。
- 记忆入口在「设置 → 扩展管理 → 记忆」。
- 设置页 90 条文案精简与视觉对齐（0.8.8 成果）。
- 动态背景的 `drawWithCache` + 共享时钟 + 22fps 节流 + 系统「移除动画」时静止（0.8.8 成果，性能基础不推倒）。
