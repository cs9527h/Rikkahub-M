# 0.4.3 真机验收清单（用于补齐发布门禁）

本文件是给人执行的清单，不是验收入证。只有把结果填入 `docs/releases/0.4.3-acceptance.json`
并通过 `scripts/verify_release_acceptance.py` 后，0.4.3 才能从候选升级为正式版。

## 必测项

1. 覆盖安装：0.4.2（versionCode 17）→ 0.4.3（versionCode 18），聊天记录、人格、设置、附件保留，签名校验无“包冲突”。
2. 更新日志：设置 → 关于 → 更新日志可打开、返回不闪退、断网时仍能看到当前版本说明。
3. 检查更新：点击版本号能返回“已是最新 / 发现新版本 / 具体失败原因”，不再只显示 HTTP 403。
4. 下载更新：走完下载→校验→系统安装确认，验证拒绝错误签名/低版本包。
5. 备份：立即备份、恢复、自动备份；旧加密备份首次恢复只需输入一次原口令。
6. 聊天与流式输出、多服务商、云服务器/AstrBot 连接、图片附件、搜索与删除。
7. 深浅色主题、启动动画与页面切换无明显掉帧。
8. 冷启动 5 次取中位数（毫秒），对比 0.4.2 同机数据。
