## Rikkahub-M 0.3.1

本次为 0.3.0 的修复版，只做状态判定与视觉修正，不改变数据结构。

- 记忆中心先读取服务器 `/capabilities`：区分「未接入长期记忆」「未配置记忆中心」「只读」「可写」，不再把读取失败当成写入被关闭。
- 读取失败时清空列表并显示具体原因：HTTP 404（网关缺接口，需更新服务器）、401/403（设备未授权或被拒）、503（记忆服务未就绪）都有中文提示；不再显示“空列表成功”。
- 校验 `/memory` 返回结构（`items`、`write_enabled`），服务端格式不兼容时明确报错，而不是当成空记忆。
- 云服务器图标重做为线形云加三个连接点，去掉上传箭头隐喻；模型图标与设置入口共用同一套深浅色配色，尺寸统一为 24dp。
- 验证签名与 0.2.4/0.3.0 完全一致，可直接覆盖升级，versionCode 12。
- 服务器记忆库仍需按部署步骤配置 `APP_MEMORY_DB_PATH`、`APP_MEMORY_OWNER_ID` 与写入开关；客户端无法替代服务端部署。

服务器侧上线步骤见 dafayu-android 仓库 `docs/MEMORY_CENTER_DEPLOY_0.3.1.md`。
