# 1.1.6 技术说明

## 版本与范围

- 上一正式版：`v1.1.5`；开发基线：`caa3a669d063af6f14f1be4d8cccfa7df0252e55`。
- 版本：`1.1.6 / versionCode 63`，包名`com.rikkahub.mate`，沿用原签名和arm64-v8a+x86_64通用APK策略。
- Room schema保持不变；备份附件增加avatars目录，保留旧布局导入兼容性，不宣称高版本数据库向上游回退。

## 核心修复

1. 当前用户/助手头像与聊天附件分区，旧upload头像按真实设置复制、CAS更新、持久化后再清理；共享、背景、预设、收藏及运行时仍在引用的原图保留。
2. 发送inbox、submitting和会话历史的引用信号进入文件归属；完整运行时快照替代同会话旧DB归属，未发草稿只保护删除，不冒充已发送。
3. 大节点以SQLite codepoint分块读取并流式解析，保持有界扫描、取消及未知引用保护；归属不依赖用户给助手起的名字。
4. 取消或被淘汰的选图释放pending，重启可回收头像目录残留；设置引用遍历不生成整份JSON副本，包含编码文件名和嵌套文本/键保护。
5. 助手编辑显式使用渲染快照，避免迁移期间编辑其他字段复活旧图片；备份先对核心资产拍磁盘快照，两种导出都使用快照并去重。
6. 快速导入第2步去名字、内部逗号/末尾句号；语音介绍简化，8套语言同步。

详细范围与已知验证边界见[功能修复记录](<../features/storage-avatar-fixes.md>)。
