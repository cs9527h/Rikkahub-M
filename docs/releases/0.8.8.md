# Rikkahub-M 0.8.8

发布策略：以 PR #37 的「聊天与设置 UI 收敛」为基线，补完三件事：把「顶部泛白 / 背景纯白」从根因上修掉、把消息操作栏与设置文案收到合适密度、把删除误触这个真实风险堵上。无数据库迁移，不动包名与签名。

## 一、顶部泛白与背景纯白

**根因**：`ChatPage` 的 topBar 外面套了一层 `Brush.verticalGradient(background alpha 0.92 → 0.55 → transparent)`。0.92 的 `background` 在浅色主题下几乎是白色，滚不滚动都盖在背景上——这就是「像蒙了一层雾」。PR #37 已删除该层；0.8.8 补上删掉之后的可读性方案。

- 标题滚动后由 `ChatTopBarCapsule` 承担底色（与左右两个按钮胶囊同源、同 haze、同边框），`showBackground = listScrolledUnderTopBar`：没滚出时 `alpha = 0`，一行都不画；滚出后淡入。**没有恢复任何全宽遮罩。**
- 浅色底渐变重做：`#BCD8F0 → #CBDEF1 → #D5E4F1 → #DCE8F3 → #E1EBF5`。末段从原来的 240/244/249 降到 225/235/245，蓝调更明确，与 `onSurface` 对比约 10:1。
- 光斑浓度整体降一档（蓝 0.72→0.44、青 0.56→0.30、淡蓝 0.62→0.36、暖 0.42→0.20），保留暖色层次但不把画面推白。
- 暗色单独一套：`#18243C → #131D31 → #0E1626 → #0A0F1B → #070A12`，中间三档保持冷调，不再出现旧的「中间发灰」。

## 二、动态背景的性能与省电

原实现每帧在 `Canvas` 里新建 4 个 `Brush.radialGradient` + 4 个 `Offset` + 4 个 `listOf`，并由 4 个独立 `infiniteRepeatable`（其中一个总长 110 秒）驱动，跟随屏幕刷新率持续重绘。

- 光斑 Brush 移入 `drawWithCache`，**按尺寸变化构造一次**；逐帧只做 `withTransform { translate(...) }` + `drawCircle`。`ShaderBrush` 的着色器按 size 缓存，canvas 平移后仍复用同一个着色器。
- 相位改为一个共享时钟，`clock.floatValue` **只在 `onDrawBehind`（绘制阶段）读取**，动画更新只失效重绘，**不触发重组**。
- 帧率节流到约 22fps（`withFrameNanos` + `delay(45)`）：漂移本身很慢，肉眼看不出，填充率省下 3~6 倍。
- 系统「移除动画」（`ANIMATOR_DURATION_SCALE == 0`）：`LaunchedEffect` 直接 return，**不启动任何动画**、不跑帧循环，只画一帧静态图（`phaseShift` 保证静态帧也错落）。

## 三、自定义壁纸遮罩

原来固定 `backgroundColor.copy(alpha = 0.20f / 0.45f)`，浅色下 `background` 就是白，等于恒有一层白雾，用户把壁纸透明度调到很低也还是白。

- 改为 `scrimAlpha = MAX_SCRIM × backgroundOpacity`（浅色 0.28 / 暗色 0.42）：**壁纸越透明遮罩越轻**，`backgroundOpacity = 0` 时遮罩为 0、一行不画。
- 遮罩色不再用纯 `background`：浅色用 `colorScheme.surface`，暗色用 `Color.Black`（只压暗、不提亮）。仍是「顶部 ×0.45、底部 ×1.0」的纵向渐变，标题区少一层膜、消息区保可读。

## 四、输入框与思考卡片

- `ChatInput` 原来是 `.imePadding().navigationBarsPadding()`：键盘弹出时导航栏已被 IME 盖住，但两个 modifier 各自按自己的 inset 相加，输入框和键盘之间多出一条导航栏高的空白带（也是「最后几条消息被顶太高」的来源）。改为 `windowInsetsPadding(WindowInsets.ime.union(WindowInsets.navigationBars))`。
- 思考卡片：预览 `heightIn(max=100.dp) → 76.dp`；渐隐 stop 加 `fadeFraction = (fadeHeight/size.height).coerceIn(0f, 0.5f)`（内容比两段 fade 短时原本会梯度逆序、渲染成硬边）；流式滚动 `animateScrollTo → scrollTo`（该 effect 的 key 是 reasoning 文本，每个 token 都重启弹簧 → 抖动）；计时 `delay(50) → 100ms`（标签按 0.1s 展示，20Hz 变 10Hz）。

## 五、消息操作栏

默认只留：复制 / 重新生成 / 更多（+ 分支选择器 + 可选时间）。其余进「更多」底部菜单：

- 朗读 / **停止朗读**（`isSpeaking` 时切换图标与动作），保留 `ttsOnlyReadQuoted`、`ttsOnlyReadOutsideBrackets` 两条过滤规则；
- 翻译（弹出语言选择对话框，`LanguageSelectionDialog`，支持清除译文）；
- 选择复制、网页预览（仅文本消息）、编辑、分享、分叉、收藏、删除；
- 用户消息的「重新生成」仍先弹确认。

**修复回归**：删除按钮从行内移进「更多」后，二次确认丢失（原实现是 3 秒内再点一次）。现在改回确认对话框——`ChatMessage` 层持有 `showDeleteConfirm`，因为 sheet dismiss 会卸载整个组合、状态放不住。同时清掉遗留的 `isPendingDelete` 死状态与对应 `LaunchedEffect`。

统计行不再堆叠「缓存」字样（详情 tooltip 里仍有 `cachedTokens`、`promptTokens - cachedTokens`、速度与耗时），能力没有减少。

## 六、设置页

- 90 条说明文案压缩到一行（例：Web 服务地址说明从 120 字三行变成「局域网用 WiFi IP，本机用 localhost」）；复杂解释留在功能内部的字段 placeholder 或点击后的对话框。
- 8 个语言文件只改字符串值：**key 数量与 HEAD 完全一致、`%1$s` 等占位符零丢失、90 个 key 的引用点全部在设置/扩展页内**（已用脚本逐文件校验）。
- 视觉对齐首页 `SettingPage` 样板：`SettingThemePage`/`SettingWebPage` 的四边 8dp 内边距改水平 16/垂直 8；5 个二级页列表间距 12dp → 16dp；6 处小节标题 `titleMedium → titleMediumEmphasized`。
- 记忆入口统一在「设置 → 扩展管理 → 记忆」（副标题「开启与管理记忆」），旧的设置首页记忆项已移除，导航无失效引用。
