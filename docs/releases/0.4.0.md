## 已实现的源码范围

- 独立 Android 客户端，模型 API 由手机直连；移除旧 Mate/AstrBot 聊天网关实现及其旧入口。
- 加密**库层**支持 PBKDF2-HMAC-SHA256 210,000 次与 AES-256-GCM（`.rkmbak`）；此构建的备份界面尚未接通口令参数，不能据此声称用户已能在 App 中完整创建和恢复加密备份。
- 明文 ZIP 默认剥离 API Key 等已知凭据字段；聊天、人格和记忆正文仍为明文，HTTPS 不能替代客户端静态加密。
- 恢复库使用暂存发布；旧网关模型配置迁移到本地供应商。全量覆盖升级、跨设备恢复和失败回滚仍需按场景验收。
