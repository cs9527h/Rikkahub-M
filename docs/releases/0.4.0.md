# Rikkahub-M 0.4.0

## 定位
独立 Android AI 客户端：模型 API 直连、人格与长期记忆本地保存、聊天本地存储；云服务器只承担加密备份存储，不再有 Mate/AstrBot 网关。

## 主要变化
- 移除旧 Mate 网关相关入口、协议与文档，客户端不再依赖云端聊天服务。
- 备份：新增可选客户端加密（PBKDF2-HMAC-SHA256 210,000 次 + AES-256-GCM，`.rkmbak`），口令不落盘；未加密路径默认剥离密钥类字段。
- 恢复：识别加密包后本地解密到临时目录，恢复完成即删除。
- 设置迁移：旧网关模型配置在升级时回落到本地真实模型，找不到时保留旧值但解析失败，避免误用云端模型。
- 备份服务端：仅保留 rclone WebDAV 容器 + nginx 反代 + Let's Encrypt IP 证书，供 App 上传加密备份。

## 签名与包名
- 包名 `com.rikkahub.mate`，沿用原签名证书（SHA-256 `e4b90a5f274074e2d8dbfa4d68226c0941635b6792716b89fd805a2318f2c94a`）。
- 单一 universal APK。

## 验证
- CI：Kotlin 编译、单元测试（含加密/迁移用例）、lint、assembleGithubDebug。
- 服务端：401 未认证、PROPFIND/MKCOL/PUT/GET/DELETE 全链路实测，容器重启后可继续读写。
- 真机验收未在本环境完成；本版按 CI + 服务端实测发布。
