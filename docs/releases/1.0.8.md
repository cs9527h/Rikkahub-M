# Rikkahub-M 1.0.8 技术说明

发布日期：2026-11-25 ｜ versionCode 55 ｜ 上一版 0.9.18

## 版本号规则变更

显示版本从 `0.9.18` 切到 `1.0.8`，之后按 **逢 10 进 1**：

```
1.0.8 → 1.0.9 → 1.1.0 → 1.1.1 → … → 1.9.9 → 2.0.0
```

- 三段各 0–9，每次发布只动修订位；到 9 进位到次位，次位到 9 进位到主位；
- `versionCode` 与显示版本解耦，每次发布 +1（0.9.18 = 54，1.0.8 = 55），保证覆盖安装不受影响；
- 规则写在 `docs/VERSIONING.md`，发布时同步的五个位置也一并记录在那里。

功能与 0.9.18 完全相同：恢复页两个入口（从本机文件恢复 / 导入原版 RikkaHub 备份）、导出只有完整备份、
WebDAV/S3/自动备份携带凭据。
