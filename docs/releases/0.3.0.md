## Rikkahub-M 0.3.0

- 聊天输入区的云服务器标识和设置入口使用统一线形图标，颜色跟随主题。
- 通过文件选择器发送附件时，逐个读取、校验并上传。网关接收原始文档和图片，避免文档正文重复计入消息字数。
- 云服务器聊天校验流式快照，检测到请求不符、内容不连续或连接提前中断时提示错误。
- 新导出的设置会移除供应商密钥、OAuth 登录凭据和 WebDAV/S3 密码等连接凭据，恢复后需重新授权。
- 聊天消息菜单可将用户选定的内容保存到当前云服务器；保存前可编辑并选择事实、偏好或经历。
- 云服务器设置支持授权后台诊断和手动发送。发送内容限定为版本、系统版本及固定错误类别。
- 停止流式生成时会取消当前网络调用；峰谷状态按服务端有效期刷新。
- 安装包同时包含 arm64-v8a 和 x86_64，以一个通用 APK 分发。
- 记忆中心新增批量软删除（服务器单事务，失败整体回滚）和操作审计视图，可看到新增、修改、删除、恢复的记录与来源设备。
- 网关错误码翻成中文；记忆库打不开时返回 503 而不是 500。
