# Rikkahub-M 0.9.18 技术说明

发布日期：2026-11-25 ｜ versionCode 54 ｜ 上一版 0.9.16（0.9.17 已取消）

## 问题

0.9.17 声称「恢复页新增导入原版 RikkaHub 备份入口」，实际**按钮没加上**：
我用脚本按旧文案做字符串替换，那段文本在 0.9.15 已经改过，`replace` 静默不匹配，于是只留下了
「兼容原版导出」的旧说明，而导出选择框又已经被删掉 —— 页面上出现自相矛盾的描述。

这类"改了但没生效"的问题编译和单测都抓不到（语法正确、逻辑未被执行），所以这一版补了两件事：

1. 修好界面：`从本机文件恢复` + `导入原版 RikkaHub 备份` 两个按钮都在，说明文案与已删除的兼容导出对齐；
2. 加了一层**断言式复核**：用 16 条 grep 断言检查近期所有行为是否真的落在代码里，本次全部 PASS：

```
本机导出带凭据 / WebDAV 带凭据 / S3 带凭据 / 自动备份带凭据
Web 服务口令仍清空 / 导出无 includeDatabase 参数
恢复页有原版备份入口 / 不再出现兼容原版文案
助手迁移一次性标志 / 备份无 passphrase 形参
stageRestoreFromStream 存在 / stageRestore 进度回调
VM restoreFromStream / UI 用 restoreFromStream
恢复进度对话框 / 已去掉逐文件 fsync
```
