## 1. 扫描方法（可复现）

所有符号级删除共用同一套证据链：

```bash
# 1) 全仓库（含 XML / manifest / web-ui / 测试）统计出现次数，排除 .git、node_modules、build
grep -rIn "\b<SYMBOL>\b" --exclude-dir=.git --exclude-dir=node_modules --exclude-dir=build .
# 结论要求：hits=0（或只命中 web-ui 下同名 TS 组件、AndroidManifest 中的类名注册）
```

辅助扫描脚本（临时，不入库，逻辑写在这里便于复核）：

1. **零引用顶层声明**：遍历 `app/src/main/java/me/rerere/rikkahub/{ui,utils}`、`common`、`ui`、`material3`，
   用正则在行首匹配 `(private|internal|…)? fun|val|var|class|object|interface|typealias <Name>`，
   再对全仓库（含 `app/src/test`、`app/src/androidTest`、`ai`/`search`/`speech`/`web`/`terminal`/
   `workspace`/`document`/`oauth`/`mediagen` 与 `*.java`）做标识符词频统计，`freq<=1` 即「只有定义」。
2. **未使用 import**：逐文件把 `import X.Y.Z [as A]` 的简单名 `Z`/`A` 在**去掉 import 行后的正文**里做
   `\bZ\b` 匹配，零命中记为候选。白名单排除 Kotlin 隐式需要的操作符/委托名
   （`getValue`/`setValue`/`provideDelegate`/`plus`/`minus`/`times`/`div`/`rem`/`contains`/`get`/`set`/
   `invoke`/`iterator`/`next`/`hasNext`/`compareTo`/`equals`/`rangeTo`/`componentN`/`unaryMinus`/`inc`/`dec`/
   `not`/`and`/`or`/`xor`），避免 `by` 委托和操作符重载被误删。
3. **未引用字符串**：解析 4 个模块的 `*/res/values*/strings.xml` 全部 key（`string`/`plurals`/`string-array`），
   按 `tools/i18n/config.yml` 的 `source_patterns` 扫描
   `*/src/main/**/*.kt|*.java`、`*/src/main/AndroidManifest.xml`、`*/src/main/res/xml/*.xml`、
   `*/src/github/**`，匹配 `R.(string|plurals|array).KEY` 与 `@(string|plurals|array)/KEY`；
   零命中即未引用。生成物注意：`tools/i18n` 直接读写 `app/src/main/res/values*/strings.xml`（`res_path`），
   没有额外的生成目录，因此不存在「不能动的生成物」。
