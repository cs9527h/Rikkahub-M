# 独立客户端：历史 Bug 清单与发布门槛

该清单源自用户此前反馈；“已修改”不等于“已通过真机验收”。配合 PR #16 与备份仓库 PR #36。

## 必须修好（P0）
- [ ] CI 编译、单测和 Lint；单个 universal APK、延续稳定签名、旧版本覆盖升级不丢聊天与本地设置。
- [ ] 网关移除后，原来自选模型不丢；对已失效的云网关模型明确要求用户配置直连模型，不静默切换至错误供应商。
- [ ] 本地提示词注入：Markdown/TXT/JSON 导入、优先级、位置、助手绑定和开关保留；新建聊天、重启、模型切换、备份恢复后保持有效。
- [ ] 消息发送红色错误、流式输出中断/重复、取消回复、图片和附件消息、通知身份/头像混乱等旧问题回归。
- [ ] 长期记忆本地 CRUD、检索、自动提取、正确召回；数据与人格注入相互独立。
- [ ] WebDAV 与 S3 上传/列表/下载/恢复/删除、网络中断、空间不足、恢复失败数据不损坏。
- [ ] 自动备份可长期运行且不会并发冲突；失败删除临时 ZIP；不把 HTTPS 误写成端到端加密。
- [ ] 客户端加密备份与可靠的恢复密钥流程，真实私密聊天上传前必须完成。
- [ ] 移除旧网关、云聊天、设备配对、服务器记忆界面与依赖，保留本地 Web server 等独立功能；无过时路由、文案、死代码。
- [ ] 默认助手、个人配置、头像、聊天记录、消息搜索、备份选项保留；不要把真实人格提示词或私人聊天上传到 GitHub。
