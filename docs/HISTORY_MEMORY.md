# 长期记忆（0.8.0）

记忆中心在**助手 → 记忆**。页面只有四件事：已经记住了什么、有没有需要你确认的、点一下整理、找不到时直接搜。

## 日常使用

1. **整理我的记忆**：只处理上次整理之后有新改动的聊天，先显示会话数量、模型服务和 Token 估算，确认后才发送。没有新聊天时不会产生任何请求。
2. **需要你确认**：整理结果里没把握的部分留在这里。审核页可以全选、按建议筛选、保存选中、按建议整理、全部跳过；每次批量操作都能撤销。
3. **我记住的**：按“关于我 / 喜好与习惯 / 重要的人 / 长期目标 / 持续事项”分组。点开可编辑、删除（进最近删除，可恢复）、查看来源。
4. **搜索**：直接问“我之前说过的阅读习惯”，下面会显示这句话在聊天时会带上哪几条记忆。
5. **记忆使用记录**：每轮聊天找到几条、注入了哪几条、模型主动读取过什么。模型最终有没有采用无法从记录判断，所以不写成“已使用”。

## 审核建议怎么来的

建议完全在本机计算，不调用模型、不产生费用：

- **建议保存**：一句话里有明确、可长期使用的信息，之前没记过。
- **可合并 / 可更新**：和已有记忆字面高度重合，或主题相同但信息更新。
- **需确认**：两条说法互相矛盾，或者涉及人物关系、个人身份、已经做过的决定。
- **建议忽略**：太短、只是提问、或者已经记过完全一样的事实。

建议只是字面比对，不代表事实一定成立；重要内容仍然由你决定。

## 数据、授权与费用

- 建立整理任务前只读取本机元数据。授权后按批发送所选会话里的**用户文字**；附件、助手回复、人格提示词和已有记忆不随请求发送。
- 同一批聊天内容有唯一指纹：换一个任务重新整理，已经处理过的内容不会第二次发送给模型，也不会重复计费。
- 单次整理和每日整理都可以在**高级设置**里设 Token 上限，达到后任务暂停并写明原因，点“继续”才重新计算单次额度。
- 任务保存已确认的会话范围、目标库和模型配置指纹。来源会话改动、设备授权失效或服务配置变动时要求重新确认。
- 备份保留未保存候选、任务状态和批次指纹；只清理本机使用记录。从其他设备恢复的任务会暂停，旧授权不会继续发送聊天。

## 实现

- Room 36 → 37 只增列增表：`history_memory_job` 增 `createdAt` / `finishedAt` / `budgetAckTokens`，新增 `memory_scope_state`（整理水位与当日用量）、`history_memory_seen`（跨任务批次指纹）、`memory_bulk_undo`（批量撤销日志）。迁移把已完成任务的记忆库水位设为迁移时刻。
- 增量按会话 `update_at` 与记忆库水位判断；批次内容按 SHA-256 去重。单条会话被编辑会从头解析，但相同批次不会再调用模型。
- 批量写入逐条幂等，失败不中断整批；撤销记录写入前内容与写入后哈希，只恢复没被用户改过的文件，候选状态一并回退到待审核。
- 候选状态变更不再清空正文与证据（旧版本会抹掉，导致无法回看或撤销）。
- 召回：中文按二元组、英文按词，分别统计标题与正文命中；需要整句命中、标题命中加正文佐证、或至少三次正文命中才注入。同标题去重，过时与删除的记忆不参与。
- 日常「做梦」仍是独立的自动整理通道，按助手设置与七天窗口运行。

## 已知限制

- 没有真机性能数据：1000 条以上记忆的长列表流畅度尚未实测。
- 增量以会话为粒度，不是消息区间增量。
- 固定（置顶）与记忆历史版本还没有实现。
