# 记忆页：选择要设置的助手

## 使用方式

在设置进入记忆页后，首屏顶部的「设置助手」卡片显示当前设置对象。点击后使用现有助手选择面板，可按标签筛选并选择其他助手；面板的编辑按钮也进入该助手的记忆设置，而不是绕到通用助手详情。

选择只改变打开的记忆设置页面，不修改当前聊天助手。每个助手使用明确带ID的独立记忆页和ViewModel；再次选择已经打开的页面会回到该页并移除它上方的页面，避免重复堆叠；返回遵循现有页面导航栈。

## 配置范围

- 启用记忆、共享库开关、自动做梦、召回预算、时间提醒、最近聊天引用和使用记录，写回所选助手。
- 浏览共享或独立记忆库仍只是查看范围，不擅自改变聊天实际使用的记忆库。
- 整理预算配置与整理模型仍为全局设置，页面已明确标注；每日预算用量按记忆库分别统计。

## 隔离保护

- 保存时基于实际渲染快照，只合并发生变化的8个记忆/提醒字段，不覆盖最新名称、提示词、模型或其他未修改设置。
- 不影响当前聊天助手ID，不覆盖其他助手，也不重新插入已删除的助手。
- 明确指定的助手被删除后显示不可用页面，可重新选择其他助手；不会退回并编辑当前聊天助手。
- 删除、恢复、永久删除的目标记忆库在调用时捕获；切换记忆库后，旧文件确认框会清除。
- 记忆文件深链等待助手与实际记忆库就绪后才处理，失效的助手页面不弹出旧操作对话框。
