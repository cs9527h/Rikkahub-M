## 助手归属规则

归属来自持久化会话中的真实附件，覆盖所有消息分支和嵌套工具输出。不依据当前选中的助手、文件名或普通文本猜测。

同一文件可被多个助手引用，因此有「共享」「未关联」「归属待确认」分类；按助手筛选不会移动或复制文件。移动/删除会话后由Room失效通知重新计算。

不新增数据库字段、不迁移schema。读取使用16节点keyset页与一节点解析树，构建路径哈希索引，避免每个文件重复扫描全部历史。扫描有上界且支持取消；频繁生成时合并更新而不无限重启。

超大、损坏、过深或不完整的历史标记为「归属待确认」，不假装没有关联。默认批量清理只处理明确未关联的文件，且只针对打开清理面板时当前筛选结果的快照；涉及引用/共享会再次确认。

## 预览和导出边界

- 文本读取128KiB，Markdown渲染32KiB，截断有提示。
- PDF单页渲染限制300万像素，文件描述符、页面和renderer在IO关闭。
- Office/EPUB使用现有解析器并补预览专用解压/输出限制；超限或损坏时不把错误文本当正文，可外部打开/导出。
- 文件读取、扫描、解析、PDF渲染和导出复制均在IO进行；FileProvider只授予临时读权限。
- 系统目标文档写入失败可能留下部分副本，不擅自删除用户所选目标；原文件保留。
- 当前入口仍管理原有聊天附件upload目录，不把独立媒体创作、工作区文件混入助手附件统计。
